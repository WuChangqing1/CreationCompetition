# 07 环境与依赖说明

> **本项目唯一推荐和允许的 Conda 环境：`dachuangxiangmu`。**

## 标准 PowerShell 检查

```powershell
conda activate dachuangxiangmu
$env:CONDA_DEFAULT_ENV
where.exe python
python -c "import sys; print(sys.executable)"
python -m pip -V
```

`CONDA_DEFAULT_ENV` 必须为 `dachuangxiangmu`，Python 和 pip 路径都必须位于该环境目录。

## Agent shell 无法 activate 时

本次 Codex shell 的 `conda activate dachuangxiangmu` 返回 `Run 'conda init' before 'conda activate'`。因此后续开发和测试强制使用：

```powershell
conda run -n dachuangxiangmu python experiments\smoke_test.py
```

这不是换环境，而是显式要求 Conda 在同一个 `dachuangxiangmu` 环境中执行命令。绝不能在 activate 失败后继续使用系统 Python。


使用 `python -m pip` 能保证 pip 属于当前 Python；裸 `pip` 可能指向系统 Python 或其他环境。

## 复现与性能

默认 seed 为 3407，并设置 Python、NumPy、PyTorch 和 CUDA seed。启用严格确定性可提高复现性，但可能降低速度或限制某些 CUDA 算法；实验报告必须注明实际设置。

正式八模型实验使用 `--device cuda`。MLP、BiLSTM、LightWeightTrans、LMF、MulT、OurModel 通过 PyTorch CUDA 运行，XGBoost 使用 `device=cuda` 与 `tree_method=hist`；SVM 受算法实现限制，仅使用 CPU。若 CUDA 不可用，PyTorch 正式模型会直接报错，不再静默回退 CPU。
