## 使用统一多模型框架

代码目录：

```text
D:\CodingData\Competition\GuoChuang\MPDD-main
```

所有 Python 命令只在 `dachuangxiangmu` 环境执行。

### 2025 Elder / Track1

```powershell
conda activate dachuangxiangmu
cd D:\CodingData\Competition\GuoChuang\MPDD-main

conda run -n dachuangxiangmu python experiments\smoke_test.py --dataset-year 2025 --cohort Elder --data-root D:\Files\Works\CreationProject\test\2025 --audio-feature mfccs --video-feature densenet --split-window 1s

conda run -n dachuangxiangmu python experiments\run_model_cv.py --model mlp --dataset-year 2025 --cohort Elder --track Track1 --task binary --data-root D:\Files\Works\CreationProject\test\2025 --audio-feature mfccs --video-feature densenet --use-personality --split-window 1s --folds 5 --seed 3407
```

### 2025 Young / Track2

将上面命令改成：

```text
--cohort Young --track Track2
```

### 2026 Elder / Track1

```powershell
conda run -n dachuangxiangmu python experiments\smoke_test.py --dataset-year 2026 --cohort Elder --data-root D:\Files\Works\CreationProject\test\2026 --audio-feature mfccs --video-feature densenet

conda run -n dachuangxiangmu python experiments\run_model_cv.py --model mlp --dataset-year 2026 --cohort Elder --track Track1 --task binary --data-root D:\Files\Works\CreationProject\test\2026 --audio-feature mfccs --video-feature densenet --use-personality --folds 5 --seed 3407
```

### 2026 Young / Track2

将上面命令改成：

```text
--cohort Young --track Track2
```

2026 的 `mfccs` 参数会自动映射到 Elder 的 `mfcc` 和 Young 的
`mfcc64`；音视频事件文件名也会自动配对。

## 2026 独立测试集

统一多模型框架当前用 trainval 做 subject-level 5-Fold 公平比较。独立测试集应在模型确定后只评估一次。使用 2026 官方工程时：

```powershell
cd D:\Files\Works\CreationProject\test\MPDD-AVG-2026-main

conda run -n dachuangxiangmu python test.py --checkpoint <checkpoint.pth> --data_root D:\Files\Works\CreationProject\test\2026\MPDD-AVG2026-test\Elder --split_csv D:\Files\Works\CreationProject\test\2026\MPDD-AVG2026-test\Elder\split_labels_test.csv --personality_npy D:\Files\Works\CreationProject\test\2026\MPDD-AVG2026-trainval\Elder\descriptions_embeddings_with_ids.npy --device cuda
```

Young 测试把三个路径中的 `Elder` 改为 `Young`。
