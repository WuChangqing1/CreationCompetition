# MPDD 2025/2026 八模型对比实验结果与消融实验设计

更新日期：2026 年 9 月 8 日

## 摘要

本文在 MPDD 2025 与 MPDD-AVG 2026 老年人（Elder）Track1 二分类任务上，对 SVM、XGBoost、MLP、BiLSTM、LightWeightTrans、LMF、MulT 和 OurModel 八种模型进行了统一对比。所有模型采用相同的 MFCC 音频特征、DenseNet 视觉特征和人格向量，使用按受试者划分的五折交叉验证，并在独立测试集上对五个折模型的类别概率进行等权集成。

两年共 16 个“年份—模型”组合均完成五折训练，独立测试共生成 32 行结果（事件级和受试者级各 16 行），全部状态为 `PASS`。以预先约定的受试者级 Macro-F1 为主要指标，2025 年表现最好的模型为 MLP，Macro-F1 为 0.8268；2026 年表现最好的模型为 LightWeightTrans，Macro-F1 为 0.7319。两年没有出现同一个模型同时取得第一名，说明模型排序受数据年份和分布变化影响明显。OurModel 在 2025 年受试者级 Macro-F1 为 0.6841，在 2026 年为 0.6920，当前结果不支持将其表述为八模型中的最优方法。

本报告中的对比结果可以作为阶段性论文结果使用，但正式投稿前仍建议完成预先定义的消融实验、多随机种子重复实验和配对统计检验。独立测试集应只用于最终报告，不应继续用于选择结构、调参或决定损失权重。

## 1. 实验问题与评价口径

本实验回答以下问题：在相同输入特征、数据划分和训练预算下，八种分类模型在 MPDD 2025 与 MPDD-AVG 2026 老年人二分类任务上的泛化性能如何；模型在事件级和受试者级评价下是否保持一致排序；OurModel 的各组成模块是否确实带来可重复的性能增益。

主要评价指标为受试者级 Macro-F1。该指标先对同一受试者的全部事件预测概率求平均，再得到受试者标签，因此更符合最终面向个体筛查或识别的应用目标。事件级 Macro-F1 作为补充指标。Accuracy、Weighted-F1、ROC-AUC、阳性召回率和特异度用于解释类别不平衡条件下的错误类型。混淆矩阵统一记为 `[[TN, FP], [FN, TP]]`。

## 6. 结果讨论

第一，简单模型并未系统性弱于复杂模型。MLP 在 2025 年受试者级取得最佳结果，并在两个年份的受试者级 Macro-F1 描述性平均中排名第一。当前数据规模下，更复杂的跨模态交互结构可能更容易受到估计方差和分布变化影响。

第二，跨年份泛化稳定性仍是主要挑战。2025 年与 2026 年的第一名不同，且多种模型在 2026 年的性能下降。2026 测试集只有 23 名受试者，排名对少数样本非常敏感；需要通过多随机种子、配对统计检验和跨年份一致性分析判断差异是否稳定。

第三，当前 OurModel 不能作为“显著优于基线”的实证结论。其 2026 年受试者级结果与 MLP 并列第二，但 2025 年仅并列第六。后续消融实验的目标应是解释人格、视觉增强和跨模态反馈分别带来了什么，而不是预设每个组件都必须提升性能。

第四，XGBoost 在交叉验证和独立测试之间出现明显排序反转。运行期间出现的设备不匹配警告表示 XGBoost 在预测时把 CPU 输入转换到 CUDA 模型所需格式，会增加内存和时间开销，但不会使本次预测指标失效。更重要的方法学问题是验证集与测试集的泛化差距，应在后续实验中保存并分析受试者级 OOF 预测，而不是仅用事件级五折均值选型。

## 7. 有效性边界

1. 当前每种设置只使用一个随机种子，无法区分结构差异与初始化波动。
2. 当前五折汇总是事件级口径，而论文主指标是受试者级口径；后续应补充受试者级 OOF 汇总。
3. 神经网络使用固定 20 epochs 的最终轮 checkpoint，没有基于验证 Macro-F1 的早停或最佳 epoch 选择。
4. 两个独立测试集类别不平衡，2026 受试者样本量尤其有限；未计算置信区间或显著性检验。
5. 八种模型都已在独立测试集上运行。后续不得根据这些测试结果继续调结构或超参数后再次把同一测试集称为“完全未见测试集”。消融结构和统计方案应先冻结，再进行一次最终评估。
6. 2025 与 2026 的人格 ID 映射机制不同。2026 已使用 `subject_id` 修复模式重新训练，不能与旧 2026 checkpoint 混用。

## 8. 消融实验设计（待审核，尚未修改代码或运行）

### 8.1 研究目标

消融实验以 OurModel 为对象，回答四个问题：人格特征是否提供独立增益；视觉增强模块（VEM）是否改善视觉时序表征；双向跨模态反馈模块（CFM）是否优于直接拼接；音频和视觉模态是否互补。所有假设、变体和统计方法在查看消融测试集结果前固定。

### 8.2 推荐变体

| 编号 | 变体 | 音频 | 视觉 | 人格 | VEM | CFM | 目的 |
|---|---|---:|---:|---:|---:|---:|---|
| A0 | Full OurModel | ✓ | ✓ | ✓ | ✓ | ✓ | 完整模型基线 |
| A1 | w/o Personality | ✓ | ✓ | × | ✓ | ✓ | 测量人格向量的边际贡献 |
| A2 | w/o VEM | ✓ | ✓ | ✓ | × | ✓ | 测量视觉自注意力增强的贡献 |
| A3 | w/o CFM | ✓ | ✓ | ✓ | ✓ | × | 测量双向跨模态反馈的贡献 |
| A4 | w/o VEM & CFM | ✓ | ✓ | ✓ | × | × | 与简单后期拼接融合比较 |
| A5 | Audio + Personality | ✓ | × | ✓ | × | × | 测量缺少视觉信息时的性能 |
| A6 | Visual + Personality | × | ✓ | ✓ | ✓ | × | 测量缺少音频信息时的性能 |

A0 已有单种子结果，但在消融实验采用多随机种子时仍需按同一方案重新运行，避免训练次数和随机性口径不同。A5 与 A6 保留人格特征，使两者的差异主要反映音频与视觉信息；A1 单独负责回答人格贡献问题。

当前 `our.json` 中 `focal_weight=0.0`，因此主对比中的 OurModel 实际使用交叉熵训练，辅助 Focal Loss 不产生有效贡献。若论文需要讨论辅助损失，建议把它列为独立的损失敏感性实验，而不是伪装成已有完整模型的消融：固定结构为 A0，只在五折验证中比较 `focal_weight ∈ {0, 0.25, 0.5, 1.0}`，根据受试者级 OOF Macro-F1 选择一次配置，冻结后再做独立测试。

### 8.3 训练与评价流程

1. 两个年份均使用与主实验完全相同的数据清单、特征、受试者五折划分和训练预算。2025 使用 `filename` 人格映射，2026 使用 `subject_id` 人格映射。
2. 推荐使用 3 个预先固定的随机种子 `3407、2025、2026`。每个变体在每个年份运行 3 seeds × 5 folds。若只做最低成本版本，可先使用 seed 3407，但论文中必须声明单次随机种子的局限。
3. 每折保存事件级预测，同时按受试者平均事件概率，新增受试者级 OOF 指标。结构选择只依据五折 OOF 结果，不查看独立测试结果。
4. 主要报告受试者级 Macro-F1 的均值±标准差；同时报告事件级 Macro-F1、ROC-AUC、阳性召回率、特异度和混淆矩阵。
5. 对 A0 与每个消融变体计算配对差值 `ΔMacro-F1 = F1(A0) - F1(Ai)`。在相同年份、seed 和 fold 上配对，并报告均值、95% 置信区间及双侧配对置换检验结果。多重比较使用 Holm 校正。
6. 所有变体与超参数冻结后，对每个变体的五折模型进行等权概率集成，并在每个年份的独立测试集上只评估一次。独立测试结果用于最终报告，不用于继续调参。
7. 报告参数量、模型大小、推理延迟和峰值显存。对被禁用的模块同时给出总参数量与实际参与前向计算的有效参数量，避免把未使用参数计入后产生误导。

### 8.4 建议的代码组织

为保留现有代码和已训练 checkpoint，建议采用新增模块方式实现：

- 保持原 `models/our/our_model.py` 不变。
- 新增 `models/our_ablation_model.py`，继承完整模型并通过显式配置开关控制人格、VEM、CFM、音频和视觉分支。
- 新增 `experiments/ablation_registry.py`，集中定义 A0–A6，禁止使用自由字符串临时组合，确保实验名称和配置可追溯。
- 新增 `experiments/run_ablation.py`，复用现有数据解析、受试者划分、训练、checkpoint 和评估组件。
- 新增 `experiments/evaluate_ablation.py`，生成事件级与受试者级 OOF 汇总、配对统计检验和独立测试结果。
- 所有输出写入新的 `experiments/ablation_results/`，不得覆盖 `experiments/results/` 或 `experiments/results_subject_aware_2026/`。

每个消融 checkpoint 必须记录年份、变体、seed、fold、人格 ID 来源、启用模块和特征配置。Run ID 必须包含这些字段，防止不同消融设置混用。

### 8.5 实施后的验证要求

正式训练前需要验证：A0 与原 OurModel 在同一权重和输入下输出一致；每个变体能完成单 batch 前向与反向传播；禁用分支不参与前向计算；五折训练和验证受试者无交集；2026 人格向量按 `subject_id` 命中；重跑相同变体时结果文件按唯一键更新，且不覆盖主对比结果。完成这些检查后，再由用户显式启动完整消融训练。

### 8.6 论文结果表格式

正式结果建议分别按年份生成两张表。每行报告 A0–A6，每列包含受试者级 Macro-F1、相对 A0 的差值、95% 置信区间、校正后 p 值、事件级 Macro-F1、ROC-AUC、阳性召回率和特异度。A0 使用粗体，只有当差异方向和统计证据一致时才标注显著性。没有运行的数据不得填入估计值或占位成绩。

## 9. 结论

当前八模型对比已经完整产生结果。2025 年受试者级最佳模型为 MLP，2026 年为 LightWeightTrans；2025 年事件级最佳模型为 LMF，2026 年事件级最佳模型为 LightWeightTrans。OurModel 在 2026 年具有一定竞争力，但跨年份表现不稳定，尚不能宣称优于全部基线。下一阶段应按第 8 节冻结消融设计，新增独立消融模块，在不覆盖现有结果的前提下完成多随机种子五折训练、受试者级 OOF 分析和一次性独立测试。
