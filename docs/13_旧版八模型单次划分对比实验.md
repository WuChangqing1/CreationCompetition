# 旧版八模型单次划分对比实验

## 1. 实验目的

该入口用于把历史 OurModel 独立测试结果与七个基线放进同一张 2025 Elderly 对比表。它不使用 5-Fold，也不读取现有五折结果。

固定模型为：SVM、XGBoost、MLP、BiLSTM、LightWeightTrans、LMF、MulT、OurModel。

## 2. 固定实验协议

- 数据：MPDD 2025 Track1 Elderly。
- 训练/验证：固定单次划分，292 条训练事件、45 条验证事件。
- 验证集二分类分布：28 个阴性事件、17 个阳性事件。
- 随机种子：2024。
- 输入：1s MFCC + DenseNet + Personality。
- 最大序列长度：26；batch size：8；神经网络训练 300 epochs。
- MLP、BiLSTM、LightWeightTrans、LMF、MulT 按验证集 Macro-F1 选择最佳 epoch。
- SVM 只支持 CPU；XGBoost 使用 CUDA；六个 PyTorch 模型使用 CUDA。
- 独立测试：227 条事件，先按受试者多数投票，平票时用平均概率决胜，再回填到事件级。
- `our` 不重新训练，只读取历史 checkpoint；指标或混淆矩阵与历史值不一致时，整个入口在训练基线前中止。

旧 `train_val_split1` 使用 Python `set`，因此只固定 seed 仍会随进程哈希状态改变。新入口保存了已恢复的 45 条验证事件身份，不再依赖 `set` 的遍历顺序。历史日志没有保存原始 train/validation 文件清单，所以能够严格保证的是：划分规模、验证类别分布、新实验的重复运行成员一致，以及 OurModel 的独立测试结果完全一致；无法从现有证据反向证明七个基线拥有过去某次未留档运行的逐样本结果。

## 3. 完整运行命令

先由用户显式执行：

```powershell
conda activate dachuangxiangmu
```

随后在项目根目录运行以下一行命令：

```powershell
python experiments\run_legacy_comparison.py --models "svm,xgboost,mlp,bilstm,lightweighttrans,lmf,mult,our" --data-root "D:\Files\Works\CreationProject\test\2025" --historical-checkpoint "D:\CodingData\Competition\GuoChuang\MPDD-main\checkpoints\BiCFNet_1s_2labels_mfccs+densenet\best_model_2026-07-29-21.42.51.pth" --device cuda
```

命令没有 `--folds` 参数；传入该参数会直接报错。入口首先验证 OurModel 必须得到：

```text
Accuracy=0.9383
Macro-F1=0.8759
Confusion Matrix=[[187, 0], [14, 26]]
```

验证通过后才训练七个基线。本命令是完整 300-epoch 正式实验，会运行较长时间。

## 4. 输出位置

每次运行创建独立时间目录，不覆盖旧结果：

```text
experiments/results_legacy_comparison_2025/<运行时间>/
├── comparison_results.csv
├── run_config.json
├── our_historical/
│   ├── metrics.json
│   ├── run_config.json
│   └── submission.csv
├── models/<模型名>/
│   ├── config.json
│   ├── training_history.csv       # 神经网络
│   └── checkpoint.pth/model.joblib
└── predictions/<模型名>.csv
```

`comparison_results.csv` 在每个模型完成后立即更新，因此后续模型失败时，前面已经完成的结果仍会保留。论文主表应使用 `EvaluationLevel=legacy_voted_event` 的 Accuracy、Macro_F1、Weighted_F1、TN、FP、FN、TP。

## 5. 结果解释边界

历史 OurModel 行是既有权重的精确复现；其余七行是当前代码在固定旧版兼容协议下的新训练结果。不能通过改 seed、挑选测试集结果或人为投票权重来强制 OurModel 排名第一。若 OurModel 不是某个指标的第一名，应如实报告，并在消融实验中只比较同一训练协议下的 OurModel 组件变化。

该历史入口仅适用于 2025。2026 没有与 `best_model_2026-07-29-21.42.51.pth` 对应的历史真值锁，不能声称与 2025 历史日志完全一致；2026 应继续使用现有 subject-aware 训练与独立测试流程，并与本表分开报告。
