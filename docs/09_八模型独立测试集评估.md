# 八模型独立测试集评估

此入口按同一年份的五折模型等权平均类别概率，分别输出事件级与受试者级指标。它不是挑选测试成绩最高的一折。SVM、XGBoost 需要按原训练折重新拟合，因此运行仍可能耗时；其他六个模型读取已有 checkpoint 推理。

## 运行

先激活已安装依赖的环境：

```powershell
conda activate dachuangxiangmu
cd D:\CodingData\Competition\GuoChuang\MPDD-main
```

2025：

```powershell
python experiments\run_independent_test.py --models "svm,xgboost,mlp,bilstm,lightweighttrans,lmf,mult,our" --dataset-year 2025 --cohort Elder --track Track1 --task binary --data-root "D:\Files\Works\CreationProject\test\2025" --cv-results "experiments\results\raw_results.csv" --output "experiments\results\independent_test_results.csv" --audio-feature mfccs --video-feature densenet --use-personality --split-window 1s --folds 5 --seed 3407 --device cuda
```

## 数据及输出

- 2025 测试数据：`D:\Files\Works\CreationProject\test\2025\MPDD-Test`。
- 2026 测试数据：`D:\Files\Works\CreationProject\test\2026\MPDD-AVG2026-test\Elder`。
- 修复后2026五折结果与 checkpoint：`D:\CodingData\Competition\GuoChuang\MPDD-main\experiments\results_subject_aware_2026`。
- 独立测试结果：`D:\CodingData\Competition\GuoChuang\MPDD-main\experiments\results\independent_test_results.csv`。
- 预测明细：同目录下 `independent_test_predictions`，文件名包含年份、人群、模型和层级。
- 混淆矩阵：同目录下 `independent_test_confusion_matrix`。

每个模型每年输出两行：`event` 为事件片段，`subject` 为受试者。受试者结果先平均其所有事件概率再分类。混淆矩阵排列为 `[[TN, FP], [FN, TP]]`。两年八模型全部成功时共有 32 行指标。

原 `raw_results.csv` 保留五折验证结果。新 CSV 按年份、人群、模型、层级更新，同键重跑替换对应行，其他年份和模型保留。需要保留某次独立测试快照时，请为 `--output` 指定另一个新文件名。

## 复现边界

六个神经网络与 XGBoost 使用 CUDA，SVM 使用 CPU。加载特征和数据预处理仍使用 CPU。

按用户要求，新独立测试路径不进行哈希或 fingerprint 验证；保留实际折成员、折数、种子和特征来源检查。人格 ID 来源进入新 Run_ID、配置和 checkpoint 元数据，因此修复后的模型不会与旧 checkpoint 混用。

现有传统模型保存的配置不记录序列截断长度，原默认值为 5；若原训练使用不同长度，需要传入相同的 `--feature-max-len`。测试标签不得用于调参、挑选折或调整集成权重。

原 `dataset.py` 仍保留文件名推断方式。新增 `experiments/subject_aware_dataset.py` 后，修复模式按 manifest 的 `subject_id` 严格查找人格向量，缺失时直接报错。旧2026 checkpoint 使用的是历史输入方式，不能用于修复后的独立测试；必须执行本页的修复后五折训练命令。
