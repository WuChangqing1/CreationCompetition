# 04 评价指标说明

二分类 confusion matrix 写作 `[[TN,FP],[FN,TP]]`。例如真实标签 `[0,0,1,1]`、预测 `[0,1,1,1]`，矩阵是 `[[1,1],[0,2]]`。

- Accuracy：预测正确数/总数，例中 3/4=0.75。类别不平衡时可能虚高。
- Precision：预测为某类的样本中有多少是真的；框架报告两类 macro precision。
- Recall：真实属于某类的样本中找回多少；框架的 Recall 是两类 macro recall。
- Positive Recall：正类召回率 `TP/(TP+FN)`，例中 2/2=1。
- Specificity：负类召回率 `TN/(TN+FP)`，例中 1/2=0.5。
- Macro-F1：先算每类 F1 再等权平均，每个类别同等重要，是主指标。
- Weighted-F1：按各类样本数量加权，大类影响更大。
- ROC-AUC：衡量正样本概率排序能力；一个 fold 只有单一真实类别时无法定义，框架返回 N/A。
- Confusion Matrix：直观看四类判断数量，可定位模型偏向。
- Mean：多个 fold 指标的平均水平。
- Standard Deviation：fold 间波动。框架使用样本标准差；越小说明对划分越稳定。

为什么不只看 Accuracy：如果有 59 个 Negative、28 个 Positive，模型全部预测 Negative，Accuracy 仍约为 67.8%，但 Positive Recall 为 0。Macro-F1 同等关注两类，更适合作为主指标。
