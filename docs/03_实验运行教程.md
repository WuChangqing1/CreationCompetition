以下基础命令保留用于 2025 单数据根。当前机器上已整理好的 2025/2026 完整路径和新版参数请优先阅读 `08_2025与2026数据集使用说明.md`。

预期环境名是 `dachuangxiangmu`，Python/pip 路径均位于该环境。后续面向用户的命令统一假设已经成功执行 `conda activate dachuangxiangmu`，因此直接使用 `python`。

```powershell
cd D:\CodingData\Competition\GuoChuang\MPDD-main
$env:MPDD_DATA_ROOT = "<MPDD_DATA_ROOT>"
```

## 2. 检查数据和 Smoke Test

```powershell
python experiments\smoke_test.py --data-root $env:MPDD_DATA_ROOT
```

预期 Dataset 显示一个样本的 A/V/P shape 和 label；六个 PyTorch 模型显示 logits `(2,2)`，SVM 与 XGBoost 显示 PASS。若其他机器缺少 XGBoost，则仅该模型显示 SKIPPED。

## 3. 创建固定 folds

新多模型对比入口当前只承诺二分类；原 `train.py` / `test.py` 的 3 类、5 类兼容路径仍保留。fold 文件包含数据指纹、任务、seed 和折数元数据；缓存不完整或条件不匹配时会拒绝复用，确认重建才使用 `--force`。

```powershell
python experiments\create_splits.py `
  --data-root $env:MPDD_DATA_ROOT `
  --task binary `
  --folds 5 `
  --seed 3407
```

预期生成 `experiments\splits\fold_1.json` 至 `fold_5.json`。再次运行会复用；只有确认需要重建时才加 `--force`。

## 4. 跑单模型

MLP：

```powershell
python experiments\run_model_cv.py `
  --model mlp --track Track1 --task binary `
  --data-root $env:MPDD_DATA_ROOT `
  --audio-feature mfccs --video-feature densenet `
  --use-personality --folds 5 --seed 3407 --device cuda
```

OurModel：把 `--model mlp` 改为 `--model our`。正式实验必须保留 `--device cuda`；仅排错时才允许改成 `--tiny --device cpu`，tiny 不是正式实验结果。

神经网络对比采用配置文件中固定的训练轮数，并保存最终轮 checkpoint；当前框架不实现“按验证集挑最佳 epoch”。因此正式报告必须注明固定 epochs，不能把结果描述为 best-validation checkpoint。

## 5. 跑全部模型

```powershell
python experiments\run_all.py `
  --models svm,xgboost,mlp,bilstm,lightweighttrans,lmf,mult,our `
  --track Track1 --task binary `
  --data-root $env:MPDD_DATA_ROOT `
  --audio-feature mfccs --video-feature densenet `
  --use-personality --folds 5 --seed 3407 --device cuda
```

本轮 Codex 没有执行这条长时间命令。run_all 会把每个模型结果写入 `run_report.json`，一个模型失败不阻止下一个。六个 PyTorch 模型和 XGBoost 使用 GPU；SVM 没有 CUDA 实现，固定使用 CPU。`raw_results.csv` 的 `Device` 列会记录实际执行设备。

## 6. 聚合结果

```powershell
python experiments\aggregate_results.py `
  --input experiments\results\raw_results.csv `
  --output experiments\results\summary.csv
```

只有实际运行过的 fold 才会进入 summary。

## 7. 查看结果

```powershell
Get-Content experiments\results\summary.csv
Get-Content experiments\results\run_report.json
Get-ChildItem experiments\results\predictions
Get-ChildItem experiments\results\confusion_matrix
```

若 `conda activate` 未成功，不要继续运行实验；先修复 Conda 初始化并重新激活 `dachuangxiangmu`。
