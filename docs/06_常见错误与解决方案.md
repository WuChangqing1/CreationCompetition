# 06 常见错误与解决方案

每项均按“现象—原因—检查—解决”组织。

## Conda 环境错误 / 系统 Python / pip 装错环境

- 现象：`CONDA_DEFAULT_ENV` 为空、缺 sklearn，或 Python 路径是 Python313。
- 原因：PowerShell 未 conda init，activate 失败后仍继续。
- 检查：`$env:CONDA_DEFAULT_ENV`、`where.exe python`、`python -m pip -V`。
- 解决：初始化 PowerShell，执行 `conda activate dachuangxiangmu`，确认成功后再使用 `python ...`；安装依赖只用 `python -m pip`。

## ModuleNotFoundError / xgboost 未安装

- 现象：import 某模块失败；XGBoost 显示 SKIPPED。
- 原因：依赖不在 dachuangxiangmu。
- 检查：`python -c "import importlib.util; print(importlib.util.find_spec('xgboost'))"`。
- 解决：确认环境后 `python -m pip install xgboost`；不要改 base。

## CUDA unavailable / CUDA OOM

- 现象：CUDA=False，或训练报 out of memory。
- 原因：驱动/torch 不匹配，或 batch/模型过大。
- 检查：`python -c "import torch; print(torch.__version__, torch.cuda.is_available())"`。
- 解决：先用 `--device cpu`；OOM 时减 batch size/序列长度，关闭其他 GPU 程序，不写死 GPU ID。

## 数据路径错误 / Fold 不存在

- 现象：要求 `--data-root`、找不到 Training JSON 或 fold JSON。
- 原因：未设置根目录，或目录层级不符合 README。
- 检查：`Test-Path "$env:MPDD_DATA_ROOT\Training\labels\Training_Validation_files.json"`。
- 解决：设置正确 `MPDD_DATA_ROOT`，再运行 create_splits；不要把绝对数据路径写入代码。

## .npy shape 错误 / dimension mismatch

- 现象：预期二维特征，或 Linear/LSTM 输入维度不匹配。
- 原因：选错特征目录、文件不是 `[T,D]`，或 A/V 方法与 config 不一致。
- 检查：用 NumPy 打印一个音频和视频文件 shape，并运行带真实 data-root 的 smoke。
- 解决：确认 `--audio-feature`、`--video-feature` 和数据目录名称；重新生成错误特征，不用 reshape 掩盖问题。

## checkpoint mismatch

- 现象：missing/unexpected keys 或权重 shape 不同。
- 原因：旧 checkpoint 没模型元数据，或特征/类别/配置不一致。
- 检查：新 checkpoint 查看 model_name/config/feature_config；旧 checkpoint 显式传 `--model`。
- 解决：使用训练时相同模型和维度。不要用 `strict=False` 静默吞掉关键层不匹配。

## Subject leakage

- 现象：`Subject leakage detected.`。
- 原因：同一 subject 同时出现在 train_ids 和 val_ids。
- 检查：查看 fold JSON 两个列表的交集。
- 解决：删除错误 folds 后仅用 create_splits 重建；不要按 segment 随机切分。

## ROC-AUC 单类错误

- 现象：某 fold 真实标签只有一类。
- 原因：数据太少、fold 错误或非分层划分。
- 检查：查看 fold 的 val_class_distribution。
- 解决：优先修正 subject-level stratification；确实单类时 AUC 保持 N/A，不伪造 0 或 1。
