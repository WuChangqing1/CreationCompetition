# 05 实验结果说明

## raw_results.csv

每个 Run_ID×Model×Fold 一行，训练完成后产生。包含 track、task、特征、personality、窗口、全部指标、参数量、模型大小、延迟、VRAM、损失、类别平衡、seed 和状态。同一 Run_ID/Model/Fold 重跑会替换旧行，避免重复计入。比赛报告的主表应从它聚合，而不是手工抄日志。

## summary.csv

由 `aggregate_results.py` 从实际 raw rows 生成，按 Run_ID 及完整实验条件分组，格式为 `mean ± std`。适合比赛报告模型总表；只有一个 fold 时 std 为 0，不能假装是完整 5-Fold。

## predictions/

每个 fold 一个带 Run_ID 的 CSV，包含 subject_id、真实/预测标签、两类概率、fold 和 model。修改 evaluator 时可以重新算指标而不用重训。

## confusion_matrix/

有 matplotlib 时保存 fold 和 overall PNG；图轴为 True Label/Predicted Label。当前环境缺 matplotlib 时保存同名数值 CSV，并报告绘图 SKIPPED。

## raw/<run_id>/<model>/fold_<n>/

PyTorch 模型保存 checkpoint 和最终 config。checkpoint 中携带模型名、配置、特征、fold、seed。

## run_report.json

run_all 每完成一个模型就写回，包含状态、耗时、错误和时间。FAILED、SKIPPED、N/A 不等于有效实验数据。
